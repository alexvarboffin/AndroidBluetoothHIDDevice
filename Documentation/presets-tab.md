# Вкладка Presets: шапки и кнопки

Чип выбирает группу. Всё, что зависит от выбранной группы, стоит в её шапке. Импорт и экспорт не зависят от чипа: они читают и пишут весь набор групп и пресетов.

Экран сверху вниз:

1. Шапка **All presets**
2. Чипы групп, перенос строк, без горизонтального скролла
3. Шапка выбранной группы
4. Переключатель `List` / `2 cols` / `3 cols`
5. Карточки пресетов

Оба заголовка — `titleSmall`, жирный, цвет `primary`.

## All presets

Область: весь файл. Все группы и все пресеты, не выбранный чип.

Кнопки справа, `FilledTonalIconButton`, без подписи.

| Кнопка | Иконка | Действие |
| --- | --- | --- |
| Import all presets | `FileDownload` | Открыть JSON и загрузить все группы и пресеты |
| Export all presets | `FileUpload` | Сохранить JSON всех групп и пресетов |

Диалог экспорта называется **Export all presets**. В нём два выбора: `Safe only` и `Include sensitive`.

## Чипы групп

Все чипы видны сразу. Горизонтальную ленту со скроллом не использовать: тап по группе должен быть сразу, без прокрутки.

| Кнопка | Вид | Действие |
| --- | --- | --- |
| Add Group | маленький контурный кружок, иконка `Add` | Новая пользовательская группа. Это не пресет |

Остальные элементы ряда — `FilterChip`. Выбранный чип задаёт группу для шапки ниже. У встроенной группы в подписи суффикс ` * `.

## Шапка выбранной группы

Слева имя выбранной группы. Справа две кнопки одного стиля: залитый кружок `FilledTonalIconButton`, без текста. Размер не меняется при смене чипа.

| Кнопка | Иконка | Действие |
| --- | --- | --- |
| Add preset | `Add`, обычный тон | Новый пресет в выбранную группу |
| Delete group | `Delete`, `errorContainer` | Удалить выбранную группу вместе с её пресетами |

У встроенной группы (`isBuiltIn`) удаление остаётся на месте и неактивно. Кнопку не прятать: иначе шапка дёргается при смене чипа.

Два плюса различаются формой и местом:

- новая группа — контурный кружок в ряду чипов;
- новый пресет — залитый кружок в шапке группы, в паре с удалением.
