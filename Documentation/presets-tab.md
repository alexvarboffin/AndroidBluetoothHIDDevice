# Вкладка Presets: шапки и кнопки

Чип выбирает группу. Цвет, добавление и удаление этой группы стоят в меню кнопки. Импорт и экспорт не зависят от чипа: они читают и пишут весь набор групп и пресетов.

Экран сверху вниз:

1. Чипы групп, перенос строк, без горизонтального скролла
2. Карточки пресетов
3. Кнопка внизу справа. На ней иконка текущего вида. Меню сверху вниз: выбранная группа (имя и круглые кнопки цвета, добавления, удаления), затем **View**, затем **All presets**

Заголовок выбранной группы — `titleSmall`, жирный, цвет `primary`.

## All presets

Область: весь файл. Все группы и все пресеты, не выбранный чип.

Отдельная группа **All presets** в меню кнопки внизу справа, своим рядом под группой **View**.

| Пункт | Иконка | Действие |
| --- | --- | --- |
| Import all presets | `FileDownload` | Открыть JSON и загрузить все группы и пресеты |
| Export all presets | `FileUpload` | Сохранить JSON всех групп и пресетов |

Диалог экспорта называется **Export all presets**. В нём два выбора: `Safe only` и `Include sensitive`.

## Чипы групп

Все чипы видны сразу. Горизонтальную ленту со скроллом не использовать: тап по группе должен быть сразу, без прокрутки.

| Кнопка | Вид | Действие |
| --- | --- | --- |
| Add Group | маленький контурный кружок, иконка `Add` | Новая пользовательская группа. Это не пресет |

Остальные элементы ряда — `FilterChip`. Выбранный чип задаёт группу для меню и карточек. У встроенной группы в подписи суффикс ` * `.

## Выбранная группа

Группа в меню кнопки внизу справа. Заголовок — имя группы, `titleSmall`, жирный, цвет `primary`. У встроенной группы суффикс ` * `. Под ним ряд круглых `FilledTonalIconButton`, без текста. Размер не меняется при смене чипа.

| Кнопка | Иконка | Действие |
| --- | --- | --- |
| Group color | `Palette` | Цвет группы. Кружок красится выбранным цветом. `0` — без тинта |
| Add preset | `Add`, обычный тон | Новый пресет в выбранную группу |
| Delete group | `Delete`, `errorContainer` | Удалить выбранную группу вместе с её пресетами |

Цвет группы хранится в `colorArgb` и тонирует карточки пресетов этой группы: фон смешивается с цветом, иконка действия берёт его напрямую. Встроенную группу тоже можно перекрасить. Удаление встроенной группы по-прежнему неактивно.

У встроенной группы (`isBuiltIn`) удаление остаётся на месте и неактивно. Кнопку не прятать: иначе шапка дёргается при смене чипа.

Два плюса различаются формой и местом:

- новая группа — контурный кружок в ряду чипов;
- новый пресет — залитый кружок в меню, в ряду с цветом и удалением.
